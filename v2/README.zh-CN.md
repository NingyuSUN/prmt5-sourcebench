# PRMT5 v2 — 三维辅因子口袋物理与跨文献活性排序基准

[English README](README.md) · [英文详细报告](reports/RESULTS.md) · [中文详细报告](reports/RESULTS.zh-CN.md) · [研究方案](docs/PROTOCOL.md) · [数据卡](docs/DATA_CARD.md) · [模型卡](docs/MODEL_CARD.md)

**PRMT5 v2** 是一项零泄漏、基于 SHA-256 密码学封存链的结构生物物理与机器学习基准研究。本研究系统解答了 `prmt5-sourcebench`（v1）中非手性二维模型跨源迁移失效的根本原因，并将评测推进至当代精准肿瘤学最核心的前沿方向：**面向 `MTAP` 缺失型肿瘤的第二代 MTA 协同型 `PRMT5•MTA` 选择性抑制剂**（`MRTX1719`、`TNG908`、`TNG462`、`AMG 193`、`AZD3470`）。

## 核心科学发现

1. **三维实验共晶位阻“双开关”将三类 PRMT5 抑制机制严格划分为互斥象限：** 将 13 个实验测定的的人源 PRMT5 晶体结构沿催化结构域 `331` 个 $C_\alpha$ 原子叠合至 `PDB 4X61` 统一坐标系（RMSD `0.41–0.77 Å`）直接证实：
   - **状态 1（`PRMT5•SAM` + 底物口袋 THIQ，如 `4X61` `EPZ015666`、`5EML`）：** 与 `SAM:CE` 及 `Glu435` 保持安全距离（`>3.19 Å`），但在 `PRMT5•MTA` 态下因缺失 `SAM` 高半胱氨酸尾部导致 `Phe327` 向底物通道摆入约 `4.5 Å`，产生 `0.51–0.58 Å` 的剧烈原子碰撞。
   - **状态 2（`PRMT5•MTA` 协同选择性抑制剂，如 `7S1S` `MRTX1719`、`8CSG`、`8VEY` `TNG908`、`9C10` `AMG 193`、`9N3R` `TNG462`、`9T43` `AZD3470`）：** 与摆入的 `Phe327` 形成紧密芳香堆积（`3.22–3.74 Å`），同时直接侵入 `SAM` 的锍甲基 `SAM:CE` 与 `SAM` 锁定态 `Glu435` 空间（`1.30–2.17 Å` 排斥冲突）。
   - **状态 3（`PRMT5` SAM 口袋核苷类似物，如 `6CKC` `LLY-283`、`7MX7` `PF-06939999`、`6RLL`）：** 同时占据辅因子与门控残基区域（距 `SAM:CE` `0.50–1.66 Å`，距 `Phe327` `1.50–2.60 Å`）。
2. **赛道 A（`98` 个 `2024–2025` *J. Med. Chem.* 独立配对分子上的 `PRMT5•MTA` vs `PRMT5•SAM` 协同选择性预测）：** 引入 2023 年前共晶三维口袋物理特征的混合模型 `M2` 在全部模型层级上实现单调递增（主终点 `y_coop_3x` AP：`B0 = 0.4490` < `P0 = 0.5198` < `B1 = 0.5600` < `M1 = 0.5951` < **`M2 = 0.6552`**；Top-20 命中率达 **`80.0%`** [`16/20`]）。在连续选择性差值 $\Delta\text{pActivity}$ 的一致性指数（`3,421` 个可比分子对）上，`M2` 达到 **`C-index = 0.6390`**，显著优于非手性二维基线 `B1 = 0.5159`（**配对骨架自助法增益 `+0.1231`，95% CI `[+0.0462, +0.2125]`，`p < 0.001`**），`ROC-AUC` 达 **`0.6768`** vs `0.5553`（`+0.1214`，`p = 0.033`）。甚至完全不使用任何生物活性标签训练的零样本三维物理评分 `P0` 也达到 `AP = 0.5198` 与 `C-index = 0.5554`（超越有监督二维 `B1` 的 `0.5159`）。
3. **赛道 B（`182` 个 `2024–2025` 同行评审文献分子上的跨文献活性排序）同时揭示手性排序优势与刚性对接的真实物理边界：** 手性二维实验内成对排序器 `M1` 取得最高汇总虚拟筛选富集（**`Pooled AP = 0.5791`** vs 阳性率 `0.3132`；**Top-25 命中 `20/25`**，富集倍数 `2.55x`，优于 `B1 = 0.5638`）。`M2`（汇总 `AP = 0.4488`，实验内加权 `C-index = 0.4668`）在全手性开环核苷系列（`CHEMBL5544428`：**`M2 AP = 0.7181` vs `B1 = 0.3808`**，Spearman $\rho = +0.5230$ vs $-0.0236$）与二氢异喹啉酮系列（`CHEMBL6090539`：**`M2 AP = 0.6440` vs `B1 = 0.5904`**）上大幅领先，但在 `MECHSWITCH_JMC2025` 的 `PRMT5•SAM` 反向筛选实验（`CHEMBL6157149`）上受挫——因为该系列通过在活性 THIQ 母核上引入故意与 `SAM` 发生位阻冲突的基团来主动消灭 `PRMT5•SAM` 活性，而这恰恰由**赛道 A** 精准识别！
